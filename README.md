## Millennium Integration & Deck Notes

- Drop `files/plugins/init.lua` into your Millennium plugins directory.
- Configure Steam Deck auto-detection inside `files/manifests/config.json`.
- Compatible with OpenSteamTool and SLSsteam workflows.
